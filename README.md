# SQL Query - Update Customer and Property Data

**CIS 310 | SQL**

## Project Overview
This exercise focuses on creating and modifying database tables using SQL. It includes selecting records from existing tables, creating a table of larger properties, and updating or deleting property records based on specific conditions.

## Features
- Creates tables using data selected from existing tables.
- Selects properties with more than 800 square feet.
- Increases monthly rent and applies conditional rent reductions.
- Deletes records associated with a specified property owner.
- Updates selected property values to NULL.
